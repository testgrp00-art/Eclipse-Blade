TAMOVEER — OFFICIAL SWORD EDITION (NITAI STUDIO)
Version 5.2 · 23 October 2026

HOW TO PLAY
1. Open index.html in a modern browser to preview, or host over HTTPS / localhost for PWA installation and fullscreen landscape orientation support.
2. The Nitai Studio golden-sword splash loads automatically, followed by the main menu. No “Rotate Your Device” blocking screen.
3. Choose Wraith, Ember or Azure and tap ENTER THE BATTLE. This requests fullscreen and landscape mode on browsers that permit it. The FULLSCREEN button also requests landscape.
4. If the browser blocks orientation lock, gameplay remains accessible via a CSS-rotated widescreen fallback on a portrait phone. The device itself cannot be physically rotated by an HTML web page if the browser/OS refuses the request.
5. On Windows, use W/A/S/D or arrow keys, Space to jump, mouse/keys for combat; F toggles fullscreen.

OFFLINE/PWA
- The project uses only HTML, CSS, JavaScript, images and a local service worker.
- For installable PWA use a secure HTTPS host or localhost. Opened with file://, ordinary gameplay works but service worker and orientation lock may be unavailable.
- App icon, favicon, splash and menu now use the official supplied 512x512 Tamoveer logo.
